## Reading this report

Movement reflects change in the observed opposition environment around each site, not a change in any project's likelihood of a particular outcome. A site can move because new sourced opposition activity was recorded nearby, because an existing local restriction was enacted, because the county model was refit, or because the national reference set the percentiles rank against has grown. The component table in a site's brief shows which of these applies.
