# Contract: Output Files

All outputs are UTF-8 with LF line endings and contain no em-dash. The layer
column refers to `configs/layers.json`.

| File | Writer | Layer | Committed by |
|------|--------|-------|--------------|
| `qc/schema_report.md` | `qc/schemas.py` | E | pipeline.yml (patch) |
| `data/schema_run_history.csv` | `qc/schemas.py` | E | pipeline.yml (patch) |
| `data/coverage_delta_report.md` | `qc/coverage_delta.py` | E | pipeline.yml (patch) |
| `snapshots/coverage_profiles.csv` | `qc/coverage_delta.py` | not a layer (`snapshots/*`) | pipeline.yml (patch) |
| `data/label_disagreement_worklist.csv` | `label_disagreement_audit.py` | E | pipeline.yml (patch), on a green county step |
| `data/features/political.csv` | `fetch_county_features.py` | D | fetch-features.yml (existing glob `data/features/*.csv`) |
| `data/features/political_parity.csv` | `fetch_county_features.py` | D | fetch-features.yml (existing glob) |
| `data/features/political_parity.md` | `fetch_county_features.py` | D | fetch-features.yml (patch adds `*.md`) |

## `qc/schema_report.md`

```text
# Schema Report

Generated by qc/schemas.py. Do not edit by hand.

- Run (UTC): <iso>
- Mode: config <mode>, effective <mode>; consecutive clean runs <k> of <N>; switch date <date|none>
- Result: <n> failure(s), <m> allowed exception(s)

## Summary
| Schema | File | Rows | Failures | Allowed |

## Failures
### <schema>: <check> (<column>), <count> row(s)
| Row | Key | Value |
(first 50 rows per check; the count is always the full count)

## Allowed exceptions
### <schema>: <check>, <count> row(s): <reason>
(row ids, first 50)

## Information
- master_opposition.csv exact duplicate rows: <n> (no check; removal is a decision for Price)
```
