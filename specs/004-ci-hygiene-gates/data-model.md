# Data Model: CI Hygiene and Automated Constitution Gates

**Feature**: `specs/004-ci-hygiene-gates/` | **Date**: 2026-09-28

No data file changes schema. The entities below are configuration and report
shapes.

## Gate

One Constitution Check item, run the same way locally (pre-commit) and in CI.

| Field | Type | Rule |
|---|---|---|
| `id` | str | Constitution Check number, 1 to 6 |
| `local_hook` | str or null | a hook id in `.pre-commit-config.yaml`; null for gate 6 (docx) |
| `ci_step` | str | the workflow step that enforces it in CI |
| `blocking` | bool | true for gates 1 to 5 |

| Gate | Local hook | CI step |
|---|---|---|
| 1 leak | `leak-audit` | `pipeline.yml` and `gate-check.yml` "Leak audit" (existing) |
| 2 layer | `layer-audit` | `pipeline.yml` layer audit (existing), `--strict` |
| 3 selftest | `touched-selftest` | `pipeline.yml` `pytest tests/test_selftests.py` (new) |
| 4 node | `node-check` | `pipeline.yml` `scripts/check_inline_js.py` (existing) |
| 5 emdash/CRLF | `deliverable-emdash`, `csv-lf` | Vale `Hawthorn.EmDash` (new); CRLF is local only (research D3) |
| 6 docx | none | manual; no docx in this repo today |

## Hook

One entry in `.pre-commit-config.yaml`. The full list is in
[contracts/precommit-hooks.md](contracts/precommit-hooks.md).

| Field | Rule |
|---|---|
| `repo` | always `local` |
| `language` | always `system` (FR-001) |
| `entry` | a repo script path; no remote hook repos |
| `files` / `exclude` | regex. The `csv-lf` exclusion is computed at run time from `layer_audit.py --list-generated`, plus `master_opposition.csv` |
| `pass_filenames` | false for whole-repo audits (leak, layer) |
| `stages` | `pre-commit` |

**Invariant**: no hook may leave the working tree modified, except `csv-lf`,
whose rewrite is the intended fix and is followed by exit 1.

## SelftestCase

One pytest case generated by `tests/test_selftests.py`.

| Field | Type | Rule |
|---|---|---|
| `module` | repo-relative path | matches `add_argument\(["']--selftest` or `["']--selftest["']\s*(in\|==)`, or `sys.argv` equality |
| `id` | str | equal to `module`, so pytest output names the file |
| `timeout_s` | int | 120 |
| `result` | pass / fail | fail when exit is non-zero or the timeout expires; the assertion message is the combined stdout and stderr, trimmed to the last 60 lines |

**Discovery scope**: `*.py` at the root, `qc/*.py` and `scripts/*.py`.
`tests/` and `.github/` are excluded.

## SelftestCoverage

Session summary emitted once per pytest run.

| Field | Type |
|---|---|
| `selftested` | int (67 on `main` today) |
| `scanned` | int (95) |
| `untested` | list of paths (28) |

It is written to stdout and appended to `$GITHUB_STEP_SUMMARY` when that is
set (SC-004).

## MasterDiffSummary (`data/master_diff_summary.md`)

Layer E, derived and regenerable. The writer is `master_diff.py`, and it is the
only writer. The format is in
[contracts/master-diff-summary.md](contracts/master-diff-summary.md).

| Section | Content |
|---|---|
| header | the two revisions compared (short SHAs) and the generation time (UTC) |
| counts | added, removed and modified rows in the raw file (daff, no key) |
| outcome changes | a table from the clean-feed diff keyed on `project_id` + `Incident`: row label, column (`Community Outcome`, `Status` or `outcome_defensible`), old value, new value |
| detail | daff highlighter rows, capped at 200 |

**States**:

- With no previous revision (first commit, or a shallow clone without
  `HEAD~1`), it writes a header plus "no prior revision", and exits 0.
- When the two revisions are identical, it writes a header plus "no changes",
  and exits 0.
