## Coverage Gate Logic

```
n_random_total  = count of worklist rows where lifecycle_outcome != "blocked_confirmed"
n_random_coded  = count of codings where universe_id is in random-stratum set

fraction = n_random_coded / n_random_total

if fraction < COVERAGE_THRESHOLD:
    label table as "interim descriptives"
    state: "{pct}% of random stratum coded; {n_remaining} rows remaining"
    omit emergence rate
    add suppression note: "Emergence rate withheld: ... (threshold: 80%)"
else:
    print emergence rate = verified_opposition / (verified_opposition + verified_none)
    print undeterminable count alongside it (always required)
```

**Denominator for emergence rate**: `verified_opposition + verified_none` (excluding undeterminable). Undeterminable rows must always be reported alongside.

## --next Queue Logic

```
worklist = read data/negative_audit_worklist.csv in file order
random_stratum = [r for r in worklist if r["lifecycle_outcome"] != "blocked_confirmed"]
codings = read data/negative_audit_codings.csv (empty list if file missing)
coded_ids = {c["universe_id"] for c in validated_codings}
uncoded = [r for r in random_stratum if r["universe_id"] not in coded_ids]
batch = uncoded[:N]  # first N by ascending audit_order
```

If N > len(uncoded): print all uncoded and a "random stratum complete" message.
If len(uncoded) == 0: print "random stratum complete; N blocked_confirmed rows remain uncoded".

## State Transitions

```
negative_audit.py (default mode)
  → writes data/negative_audit_worklist.csv   [always regenerated]
  → writes data/negative_audit_report.md       [always regenerated]

negative_audit.py --next N
  → reads data/negative_audit_worklist.csv
  → reads data/negative_audit_codings.csv
  → prints batch to stdout
  → writes nothing

negative_audit.py --selftest
  → reads nothing
  → writes nothing
  → exits 0 or 1
```
